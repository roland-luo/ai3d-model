# 夏风 · 换装间 — 使用说明

这是一个**原创的、低多边形风格**的 3D 女性角色：三套衣服、三种肤色，可换装、可旋转、可下载。附一张 4K 海报和可以继续编辑的 Blender 工程。

先说明白三件事：

1. **不是真人复刻。** 脸是 CC0 基础素材自带的风格化脸，没有用参考照片做面部贴图，也没有照着某个人捏脸。
2. **完全离线。** 网页、模型、海报都在这个文件夹里，不需要联网、不需要装服务器、不需要付费 API。
3. **衣服是“整件切换”，不是给同一个身体套不同布料。** 三套衣服是三个独立的 GLB 模型，共用同一套 62 根骨骼和同一张脸；网页里切换的是“显示哪一套”，所以不会出现骨骼错位、比例爆炸。

## 一、最快上手：3 分钟看网页

### 第 1 步：打开换装间

**做什么**：打开可交互的换装网页。

**怎么敲**：双击 `夏风换装间.html`。

- Windows：双击，或右键 →「打开方式」→ Chrome / Edge。
- macOS：双击，或右键 →「打开方式」→ Chrome / Firefox。
- Linux：双击，或 `xdg-open 夏风换装间.html`。

**怎么算成功**：

- 出现蓝天背景和一位白裙长发角色；
- 左下角（手机上在下方）能看到「今天穿什么」和三张衣服卡片；
- 加载提示最后显示 `载入衣橱 3 / 3`；
- 页面右上角显示 `01 / 03`。

**失败查哪**：

- 双击后打开的是记事本/代码 → 右键选择浏览器打开。
- 页面一直停在加载 → 换 Chrome 或 Firefox；确认文件大小约 **4.6 MB**（文件不完整就重新拷贝一次）。
- 页面全黑/全白 → 浏览器关闭了 WebGL；在 Chrome 地址栏打开 `chrome://gpu` 看 WebGL 是否为 Enabled，或换一台有显卡加速的电脑。
- 这个 HTML 是单文件，**可以单独拷到 U 盘或桌面**，不依赖旁边的 `models` 文件夹。

### 第 2 步：换衣服、换肤色

**做什么**：试三套搭配和三种肤色。

**怎么敲**：

- 换衣服：点左侧「白裙漫步」「日常一刻」「林间探险」任意一张卡片。
- 换肤色：点下方「肤色」里的三个圆点——瓷白、暖蜜、麦色。

**怎么算成功**：

- 人物立刻换装，右上角编号变成 `02 / 03` 或 `03 / 03`；
- 衣服下方那行英文和描述同步变化；
- 换肤色时，只有**皮肤**变色，衣服、头发、腰带颜色不变。

**失败查哪**：

- 点了没反应 → 等 1 秒再点；如果仍无变化，刷新页面。
- 换肤色后衣服也变色了 → 这是不正常的，请记录你点的是哪个色点，回到项目里改 `viewer/app.js` 中只匹配 `Skin` 材质的逻辑（进阶）。
- 加载很久 → 三个模型都嵌在 HTML 里，正常家用电脑 3～10 秒；超过 30 秒请检查浏览器是否禁用了 WebGL。

### 第 3 步：旋转、缩放、复位

**做什么**：从各个角度看模型。

**怎么敲**：

- 按住鼠标左键拖动：旋转。
- 滚轮：拉近/拉远。
- 手机上：单指拖动旋转，双指捏合缩放。
- 「自动旋转」：开关缓慢自转。
- 「重置视角」：回到正面全身。

**怎么算成功**：角色跟着鼠标转，松手后有轻微的缓动；点重置后回到初始构图。

**失败查哪**：拖不动 → 鼠标是否点在角色区域（不要点在左侧卡片上）；滚轮缩放过头 → 点「重置视角」。

### 第 4 步：下载模型

**做什么**：把当前这套衣服的 GLB 存到电脑。

**怎么敲**：点左下角的「下载模型」。

**怎么算成功**：浏览器弹出下载，文件名类似 `xiafeng_dress.glb`；页面底部出现提示「已保存「白裙漫步」的 GLB 模型」。

**失败查哪**：

- 只看到提示、下载文件夹里没有文件 → 浏览器拦截了自动下载。看地址栏右侧的下载图标，允许本站下载；或直接在 `models` 文件夹里拿现成的三个 GLB，效果完全一样。
- 下载得到的文件打不开 → 它是 3D 模型，不是图片/视频；用 Blender、Unity、Godot 或 Three.js 打开，见下一节。

### 第 5 步：看素材与许可

点页面底部「素材与许可」，会弹出说明：角色来源、渲染引擎、脸部说明、使用边界。点右上角 × 或按 Esc 关闭。正式许可文本在本文件夹的 `素材许可.txt`。

### 每个文件是干什么的

| 文件 | 是什么 | 什么时候用 |
|---|---|---|
| `夏风换装间.html` | 单文件网页，Three.js 和三个 GLB 全部嵌在里面 | 只想看效果、换装、下载模型 |
| `models/*.glb` | 带骨骼、材质和 Idle_Neutral 动画的 3D 模型 | 导入 Blender / Unity / Godot / 网页项目 |
| `blender/*.blend` | Blender 源工程 | 想改颜色、改发型、改灯光、重渲 |
| `poster/*.png` | 4K 竖版海报 | 发朋友圈、做壁纸、打印小样 |
| `poster/*.jpg` | 1080×1920 预览 | 手机查看、发给别人看 |

### 模型规格

- 身高：约 **1.84 米**（Blender 默认单位，米）。
- 骨骼：**62 根**，其中 38 根是手指骨（每只手 19 根）；脚部没有单独脚趾骨。
- 网格：4 个蒙皮网格（头、身体、腿、脚）；白裙版额外有一条长发片。
- 动画：每个 GLB 带一段 `Idle_Neutral`（待机）动画；挥手姿势已经冻结在 `blender/poster.blend` 里，默认 GLB 只保留待机动作，避免文件变大。
- 朝向：Blender 中面向 −Y；导入引擎后按引擎的坐标系自动转换。
- 材质：`Skin`（皮肤）、`LimeGreen`（白裙主色）、`Gold`（腰带）、`Red`（发帽/鞋）、`Brown`（眼眉）、`Hair_Long`（长发片）。三个肤色切换只改名称以 `Skin` 开头的材质。

## 三、把 GLB 用起来

### 在 Blender 里打开

**做什么**：导入模型，确认骨骼和动画都在。

**怎么敲**：

1. 打开 Blender 4.2 或更新版本。
2. 菜单 `File → Import → glTF 2.0 (.glb/.gltf)`。
3. 选择 `models/outfit_dress.glb`，点 `Import glTF 2.0`。
4. 按 `Numpad 1` 看正面；按 `Space` 播放待机动画。

**怎么算成功**：

- 大纲视图里出现一个 `Armature` 和 4 个基础网格；白裙版还会多一条 `HairSheet` 发片，共 5 个网格；
- 模型高约 1.84 m，脚踩在网格地面附近；
- 按空格，人物有轻微的呼吸/待机动作；
- 材质球里能看到 `Skin`、`LimeGreen`、`Gold`、`Hair_Long` 等。

**失败查哪**：

- 模型巨大或极小 → 检查场景单位（`Scene Properties → Units → Unit Scale` 应为 1.0），不要急着 Apply Scale。
- 没有动画 → 在 `Dope Sheet` 把模式切到 `Action Editor`，选择 `Idle_Neutral` 动作。
- 材质发黑 → 视口右上角把 `Solid` 切成 `Material Preview`；GLB 用的是 Principled BSDF，不需要额外贴图。
- 白裙版有两条“头发” → 一条是发帽（网格 `Formad_Head` 的 `Red` 材质），一条是长发片（Blender 源文件里叫 `LongHair`，导出的 GLB 里网格名是 `HairSheet`；材质 `Hair_Long`），这是正常的。

### 在 Unity / Godot / Three.js 里打开

- Unity：原版 Unity 不直接认 `.glb`，先装一个免费的 glTF 导入插件（常用 `glTFast`，在 Package Manager 里按名称添加）；装好后把 `.glb` 拖进 `Assets`，在导入面板里勾选动画，再把模型拖进场景。
- Godot：直接拖进文件系统，双击场景，用 `AnimationPlayer` 播放 `Idle_Neutral`。
- Three.js：用 `GLTFLoader` 加载；模型自带骨骼和动画，不需要额外绑定。

## 四、改颜色 / 改皮肤（Blender）

### 换皮肤颜色

1. 打开 `blender/dress.blend`。
2. 选中身体、头、腿（或直接在大纲里选网格）。
3. 右侧 `Material Properties` → 找到 `Skin`。
4. 改 `Base Color`，比如：
   - 瓷白：`#E8C0A2`
   - 暖蜜：`#CD9468`
   - 麦色：`#A0693F`

网页里的三个色点就是这三个值；改完渲染，颜色会跟着骨骼/灯光一起正常显示。

### 换衣服颜色

- 白裙主色：材质 `LimeGreen`（名字来自原始素材，实际已经是白色）。
- 腰带：`Gold`。
- 头发帽 + 鞋子：共用 `Red`。**注意**：改 `Red` 会同时改发帽和鞋子；如果只想改头发，需要复制一份材质并重新分配面，或只改长发片 `Hair_Long`。
- 眼眉：`Brown`。
- 长发片：`Hair_Long`。

### 换姿势 / 改风动

- `blender/poster.blend` 里已经是“挥手 + 裙摆向左、头发向右”的海报姿势；打开后按 `F12` 就能重渲。
- 这个场景的裙摆和头发做了顶点级风动；如果想让风更大，改 `scripts/woman/poster_render.py` 里的位移系数，再重新跑渲染。
- 不建议直接把三套衣服在 Blender 里合并成一个骨架：三套模型共用骨骼但网格各自独立，网页采用“独立 GLB + 显示切换”的方式，最稳。

## 五、海报怎么用

- 尺寸：**2160 × 3840**，9:16 竖版，sRGB。
- 300 dpi 打印约 **18.3 × 32.5 cm**；做手机壁纸、聊天预览、A4 以内小样都够用。
- 想印更大，打开 `blender/poster.blend`，把渲染分辨率按比例加到 3240×5760 或 4320×7680，再重新合成排版。
- `夏风海报_无字版_4K.png` 没有任何文字，适合你自己加标题、做封面或二次排版。
- 海报里的文字是**图片的一部分**，不是可编辑文本；要改字，需要用 `scripts/woman/poster_compose.py` 重排（见下一节）。

## 六、进阶：重新生成海报

> 这一段是给想改图的人看的。只看网页/拿模型的话，可以跳过。
> 下面的命令使用本机项目目录 `/home/roland/ai3d`；交付包里只有成品文件，没有这些开发脚本和 `viewer/` 源码。

**做什么**：重新渲染角色 + 重新生成天空 + 重新排版，得到新的 4K 海报。

**怎么敲**：

```bash
cd /home/roland/ai3d

# 1) 用 Blender 渲染透明背景的角色（CPU，几分钟）
blender -b --python scripts/woman/poster_render.py -- final \
  /home/roland/ai3d/projects/woman01/renders/poster_char_final.png 20

# 2) 生成程序化蓝天/云/太阳背景（几秒）
.venv/bin/python scripts/woman/poster_sky.py

# 3) 合成角色 + 排版 + 颗粒（几秒）
.venv/bin/python scripts/woman/poster_compose.py final
```

**怎么算成功**：

- 第 1 步最后打印 `WROTE .../poster_char_final.png`；
- 第 2 步打印 `WROTE poster_sky.png`；
- 第 3 步打印 `WROTE .../夏风海报_4K.png`；
- 用图片查看器打开，尺寸是 2160×3840。

**失败查哪**：

- `blender: command not found` → 用 `~/.local/bin/blender` 代替 `blender`。
- `ModuleNotFoundError: numpy` / `PIL` → 用项目里的 `.venv/bin/python`，不要用系统 `python3`。
- 字体不对/缺字 → 安装 Noto Serif CJK SC 和 Noto Sans CJK SC；或改 `scripts/woman/poster_compose.py` 顶部的字体路径。
- 想换文案 → 改 `scripts/woman/poster_compose.py` 里 `add_text()` 的几行中文，重新跑第 3 步。
- 想改网页 → 改 `viewer/app.js` 或 `viewer/index.html`，然后运行 `python3 scripts/woman/build_offline.py` 重新打包成单文件 HTML。

> 小提醒：`.venv` 只是给海报脚本用的（numpy + Pillow，约 106 MB），和网页运行无关。网页不需要 Python。

## 九、常见问题

**Q：网页需要联网吗？**
A：不需要。Three.js、三个模型和全部界面代码都在这一个 HTML 里。断网、飞行模式都能用。

**Q：为什么网页里的脸没有嘴？**
A：这是 Quaternius 基础资产的风格化设计（眼眉是几何面片，嘴部极简）。海报为了保持同一角色的辨识度，也没有另画嘴。它走的是低多边形/风格化路线，不是写实人脸。

**Q：能商用吗？**
A：基础角色是 CC0，可以商用；Three.js 是 MIT，保留版权声明即可。海报里的字体是 OFL，栅格化使用没问题。具体项目仍建议你自己复核一遍许可文本。

**Q：能改成别的发型/衣服吗？**
A：可以。Blender 工程里头发是独立网格，衣服是独立材质；你可以加发片、改裙子长度、换颜色。改完导出 GLB，再按 `build_offline.py` 重新打包网页。

**Q：为什么三套衣服不共用一个 GLB？**
A：它们共用骨骼和脸，但网格/材质是分开的。网页加载三个独立 GLB，切换时只改可见性；这样比把三套合并进一个骨架更稳，不会出现比例或蒙皮错乱。

**Q：海报能印多大？**
A：2160×3840 在 300 dpi 下约 18×32.5 cm。A4 小样没问题；再大建议用 `poster.blend` 提高分辨率重渲。

**Q：下载按钮没反应？**
A：先看浏览器是否拦截下载；其次直接用 `models` 里的三个 GLB。网页的下载只是把内嵌的 GLB 存出来，文件本身和 `models` 里的一致。
